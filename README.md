Armado Web - Login Responsive

Proyecto desarrollado como parte de la materia de Desarrollo Web. El objetivo fue replicar una interfaz de inicio de sesión utilizando HTML y CSS, aplicando conceptos de maquetación web y diseño responsive.

Características:

Estructura semántica con HTML5.

Diseño basado en CSS Grid.

Uso de Flexbox para alineación y centrado de elementos.

Formulario de inicio de sesión moderno.

Diseño inspirado en una interfaz profesional de login.

Tecnologías Utilizadas:

HTML5

CSS3

CSS Grid

Flexbox


Funcionalidades:

Visualización del formulario de inicio de sesión.

Campos de correo electrónico y contraseña.

Enlace para recuperación de contraseña.

Enlace de registro (Sign Up).

Diseño responsive para computadoras y dispositivos móviles.

Durante el desarrollo del proyecto se aplicaron los siguientes conceptos:

Etiquetas semánticas (main, section, form).

Selectores y propiedades CSS.

Distribución de contenido con CSS Grid.

Alineación mediante Flexbox.

Organización y estructura de proyectos web.
